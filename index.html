Getting games in

  1. Copy and paste (works everywhere): Chess.com app → open the game → Share → Copy PGN → open Blundercheck → Paste game & analyze.
  2. Recent games: with your username set, your latest Chess.com games appear on the Analyze tab. Tap one.
  3. Share sheet (optional): set up the iOS Shortcut described in the README so "Blundercheck" appears when you tap Share. It opens the game in Safari.
